# req-055 · ProcessTrace 执行时间线 UI

## 背景

当前 P3 的对话气泡视图只展示最终文字，AI 执行过程（思考、工具调用、轮次）对用户不可见。用户无法在执行过程中理解 AI 在做什么，也无法在合适时机干预。

ProcessTrace 将每次 AI 响应的完整执行过程以结构化时间线展示：按轮次分组，每轮显示思考块和工具调用，可折叠，最终回答在时间线末尾显示。

## 渲染规则

| 场景 | 渲染方式 |
|------|---------|
| 有工具调用的响应 | 按轮次折叠的 ProcessTrace 时间线 |
| 纯文字响应（无工具调用） | 直接渲染文字，不显示 ProcessTrace 包装 |
| 含中断干预的响应 | 时间线中插入干预记录卡片（req-057） |
| 历史节点 | 从 QA atom `## Steps` 读取，渲染方式与运行时一致 |

## 视觉参考

AgentOS（xue160709/AgentOS）的 ProcessTrace 组件交互模式（折叠节奏、工具状态展示、间距）。
视觉语言使用 req-058 建立的 Design Token 体系，组件独立实现。

## 验收标准

- [ ] 有工具调用的响应显示轮次分组时间线，每轮可独立折叠
- [ ] 思考块内容在轮次内可展开查看
- [ ] 工具调用显示：工具名 + 输入摘要 + 执行状态（进行中/成功/失败）
- [ ] 工具结果可展开查看完整内容
- [ ] 纯文字响应不显示轮次包装，直接渲染
- [ ] 历史节点打开时能正确从 `## Steps` 渲染完整时间线
- [ ] 运行时流式追加与历史回放视觉一致
