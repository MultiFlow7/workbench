# req-017 · Agent 执行流视图

## 需求描述

当用户进入某个 Agent 任务的详情视图时，可以看到该 Agent 的实时执行流——类似命令行的思考过程和操作输出，但以结构化 UI 呈现，而不是纯文本日志。

## 内容构成

每个执行流条目包含：
- **类型标签**：`思考` / `工具调用` / `文件写入` / `决策` / `输出`
- **内容摘要**：该步骤做了什么（可展开查看详情）
- **时间戳**
- **状态**：进行中 / 已完成 / 失败

## 交互要求

- 实时流式更新（Agent 运行中时追加条目）
- 可折叠/展开每个条目的详情
- 支持搜索和筛选（按类型过滤）
- 用户可以在执行流中找到某个决策节点并插入修正指令（打断并重新引导）

## 与当前命令行的关系

v0.1 的命令行输出是这个功能的原始形态。v0.x 演化方向：
- 结构化解析 Agent 的输出（tool_use / text / decision）
- 在 UI 中分层渲染，而不是滚动文本

## 讨论记录

**2026-05-18**：用户指出命令行里的思考过程流是雏形，但需要更完善的 UI 呈现。这是 human-first 可视化在 Agent 平面视角的具体实现。
