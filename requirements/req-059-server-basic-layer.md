# req-059 · 服务器基础接入层

## 背景

用户的 Agent 团队未来需要在云端持续运行（关机不中断）。本需求是这一能力的基础层：将「Agent 在哪里运行」变成一个可配置的选项，而不是硬绑定在本地。

## 核心概念

Agent 是有**部署位置**的执行单元。同一套工作台前端，连接本地 Agent 或远程 Agent，体验一致：

```
启动 Agent
  ├── 本地运行  → Electron 主进程内运行 Claude Code SDK
  └── 服务器运行 → 连接用户服务器，服务器上运行 Claude Code SDK
```

## v0.15 范围（基础层）

| 功能 | 说明 |
|------|------|
| 服务器配置 | 设置页配置服务器地址 + 认证 Token |
| 连接健康检查 | 显示服务器连接状态（在线/离线） |
| 部署位置选择 | 启动任务时选「本地」或「服务器」 |
| 服务器侧执行 | 服务器运行 SDK，工作台通过 WebSocket 接收实时事件流 |
| 关机不中断 | 工作台关闭后服务器 Agent 继续运行 |
| 结果查看 | 重新打开工作台后可查看已完成任务的状态和结果 |

## 服务器端要求（用户自行部署）

Node.js + Claude Code SDK 运行环境。工作台提供部署文档。

## 不在本需求范围

- Agent 团队云端统一部署和管理（v0.16）
- 服务器侧文件系统访问
- 定时/事件触发

## 验收标准

- [ ] 设置页可配置服务器地址 + Token，配置持久化
- [ ] 连接健康检查实时显示服务器状态
- [ ] 启动 Agent 时显示「本地 / 服务器」选择入口
- [ ] 选择服务器后，Agent 在服务器上运行，工作台 P3 实时显示 ProcessTrace 事件流
- [ ] 工作台关闭后服务器 Agent 继续运行
- [ ] 重新打开工作台，服务器 Agent 的运行状态和结果可查看
