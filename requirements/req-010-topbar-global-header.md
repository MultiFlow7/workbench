# req-010 · TopBar 全局顶栏

## 需求描述

在应用最顶部放置一条固定 36px 高的全局顶栏，承载三类信息：左侧侧栏折叠控制、中间应用标识、右侧基础设施服务健康指示灯。TopBar 贯穿整个窗口宽度，位于四面板布局之上，所有模式下常驻可见。

## 用户价值

- 用户无需切换到「控制台」模式即可感知 sub2api / n8n / API Layer 三个后端服务的当前状态，异常时第一时间可见。
- 在任意面板状态下都能快速折叠/展开 P1 侧栏，释放横向空间。
- 应用标题提供视觉锚点，减少在多窗口环境中的误操作。

## 验收标准

- [x] TopBar 高度固定为 36px，宽度占满窗口，位于四面板布局上方
- [x] 左侧含侧栏折叠按钮，点击后 P1 图标栏与列表栏同步切换折叠状态
- [x] 中间显示「工作台」文字标题
- [x] 右侧显示三个服务状态指示灯：sub2api、n8n、API Layer
- [x] 指示灯具有在线（绿）/ 离线（红）/ 检测中（灰/动画）三种视觉状态
- [x] 指示灯标注服务名称，鼠标 hover 可见服务地址或详情
- [x] TopBar 背景色与整体浅色主题一致，与下方面板有视觉分隔

## 实现说明

已在 v0.1 实现。TopBar 以独立 React 组件实现，通过 Zustand store 读写 P1 折叠状态。服务状态通过前端定时轮询各服务健康检查端点获取，结果写入 store 供指示灯组件订阅。
