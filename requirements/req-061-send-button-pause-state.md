# req-061 · 发送按钮运行状态感知（运行时变全局暂停）

## 背景

v0.15 的暂停干预触发点在 P3 header 的独立 ⏸ 按钮。

本需求将触发逻辑迁移到输入区发送按钮：Agent 运行时，发送按钮变为全局暂停按钮；非运行时恢复为发送按钮。这与主流 AI 界面一致，不占额外布局空间。

## 交互规则

| 状态 | 输入区按钮 | 点击行为 |
|------|-----------|---------|
| 空闲（可发送） | 发送 ▶ | 提交当前输入，发起对话 |
| Agent 运行中 | 暂停 ⏸ | 触发 PreToolUse Hook 挂起，对话流末尾出现干预输入卡片 |
| 暂停等待干预 | 按钮禁用或隐藏 | 等待用户完成干预操作 |

## 关联调整

- **移除** P3 header 上原有的独立 ⏸ 暂停按钮
- `InterventionInline` 组件保持不变，仍由暂停触发后在对话流末尾渲染
- 干预记录写入 `## Intervention`（req-057 已实现）

## 验收标准

- [ ] Agent 运行时输入区按钮视觉变为暂停图标（⏸），不可输入
- [ ] 点击暂停后 agent loop 在当前工具完成后挂起（PreToolUse Hook）
- [ ] 挂起后对话流末尾出现琥珀色干预输入卡片，自动滚动并聚焦
- [ ] Agent 完成或未运行时按钮恢复为发送图标（▶）
- [ ] P3 header 不再显示独立的 ⏸ 暂停按钮
