# req-027 · 画布 Token 分析视图

## 需求描述

在对话画布（P2 分支树）和独立分析面板中，为每个对话节点叠加 token 统计信息，并提供整棵树维度的汇总——包括各模型消耗分布、总计、最贵节点标识。数据来源全部来自 QA atom frontmatter，无需实时 API 调用。

## 功能拆解

### 1. 节点 Token 标注（P2 分支树叠加层）

每个对话节点（QA atom）在树状图上显示轻量标注：

```
[节点 0001-002]
in: 2,048  out: 512  ·  gemini-2.5-pro
```

- 默认折叠（仅显示总 token 数）
- 悬停展开显示 input/output/model 明细
- 超过路径平均值 1.5× 的节点标注「⚠ 高消耗」

### 2. 画布汇总面板（P4 或独立侧抽屉）

当用户点击「Token 分析」入口时展开，显示：

| 维度 | 内容 |
|------|------|
| 本画布总消耗 | input 总计 / output 总计 / 合计 |
| 按模型分组 | 每个模型的 input + output token 占比（饼图或条形图） |
| 最贵节点 Top 5 | 节点 ID + token 数 + 路径摘要 |
| 平均每节点消耗 | 合计 / 节点数 |

### 3. 路径维度分析

选中 P2 某节点后，P4 显示该路径（从根到当前节点）的累积 token 统计，区别于整棵树。

## 数据来源

- 遍历当前项目所有 QA atom 的 frontmatter token 字段（req-025 写入后可用）
- 若 atom 无 token 字段（旧数据），在分析视图中标注「无数据」，不报错
- 数据聚合在前端完成（对话规模 v0.x 阶段 < 1000 节点，客户端计算够用）

## 实现位置

- **`TokenAnalyticsPanel.tsx`**：新增组件，可嵌入 P4 或作为模态侧抽屉
- **`conversationSlice.ts`**：新增 selector `selectTokenSummary`，返回按模型分组统计对象
- **P2 分支树**：在现有 SVG 节点上叠加轻量 token 标注层（条件渲染，不影响默认视图性能）

## 与其他需求的关系

- 依赖 req-025（atom frontmatter token 字段）
- 补充 req-026（req-026 是单路径实时感知，req-027 是整棵树历史分析）
- 为 req-028（时序仪表盘）提供画布维度的下钻入口

## 讨论记录

**2026-05-18**：用户要求「以画布为例，我需要知道每一个 QA 消耗的 token，而且每一个 QA 对话可能调用的是不同的 Model，对应的我也要统计比如这一个完整的画布中每个模型消耗了多少 token」。画布级分析是这个需求的直接映射——以对话树为作用域，对每个节点的 token 元数据做聚合可视化。
