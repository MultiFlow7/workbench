# req-044 · P4 文本输入展开面板

## 背景与目标

P3（主工作区）底部的输入框在输入长文本时体验很差——单行或固定高度的输入框在多段落、长提示词场景下难以编辑和排版。

目标：提供一个"展开到 P4 编辑"的交互入口，让用户可以在 P4 面板的大画布上自由输入长文本，内容实时同步回 P3 输入框，发送时保持一致。

## 设计方向

### 触发方式

在 P3 输入框的右上角（或输入框内右侧）添加一个图标按钮（展开图标 `⤢` 或类似），点击后：

1. P4 面板切换为「文本输入」模式（若 P4 当前在展示节点详情，需提示或直接覆盖）
2. P4 内显示一个大型 `<textarea>`，初始内容同步自 P3 当前输入框内容

### 双向同步

- 用户在 P4 textarea 输入时，P3 输入框内容实时同步（debounce ~100ms）
- 用户在 P3 输入框输入时，P4 textarea 也同步（保持一致性）
- 用户关闭 P4 文本输入模式后，内容保留在 P3 输入框，不丢失

### P4 文本输入面板 UI

- 大面积 `<textarea>`，自动撑满 P4 可用高度，无固定行数限制
- 顶部标题区显示「文本输入」+ 一个「收起」按钮，点击退出该模式
- 底部可选：字符计数、「清空」按钮
- 样式遵循已有设计系统（Inter 字体，`--accent: #2563eb`，浅色主题）

### P4 模式切换约定

P4 当前默认展示节点详情。引入「文本输入」模式后，P4 存在两个视图状态：
- `detail`：节点只读详情（现有行为）
- `text-input`：文本输入展开面板（新增）

两者互斥，切换时保留各自状态（detail 的选中节点不丢失）。

## 待确认

1. **P4 被占用时的处理**：若用户正在查看 P4 节点详情时点击展开按钮，是直接切换还是弹出提示？建议直接切换（节点详情可通过 P2 重新选中恢复）。
2. **键盘快捷键**：是否为"展开输入"添加快捷键（如 `Cmd+Shift+E`）？

## 验收指标

| 验收项 | 标准 |
|--------|------|
| 触发按钮可见 | P3 输入框旁有展开图标，hover 有 tooltip 说明 |
| P4 切换为文本输入模式 | 点击后 P4 显示大型 textarea，原内容已预填入 |
| P4 → P3 实时同步 | 在 P4 输入，P3 输入框同步更新，延迟 ≤150ms |
| P3 → P4 实时同步 | 在 P3 输入，P4 textarea 同步更新 |
| 关闭后内容不丢失 | 点击「收起」，P4 恢复 detail 模式，P3 输入框内容完整保留 |
| 发送行为不变 | 无论是从 P3 还是（若支持）P4 发送，走相同的提交逻辑 |
| 样式与设计系统一致 | textarea 字体、颜色与已有面板风格统一 |
