# req-003 · 模式切换导航（P1）

## 需求描述

Panel 1 是左侧固定导航栏，承载三个模式图标（对话/工具/控制台）。v0.1 仅激活对话模式，工具和控制台显示为禁用态 placeholder，保留 UI 位置不做实现。

## 验收标准

- [ ] P1 宽度固定 48px，始终可见，不可折叠
- [ ] 三个模式图标垂直排列：对话（激活）/ 工具（禁用）/ 控制台（禁用）
- [ ] 点击激活的图标 → 模式切换，<200ms 完成，当前面板内容状态保留
- [ ] 当前激活模式有视觉高亮（active 态）
- [ ] 禁用态图标视觉区分（opacity 降低），hover 时提示「v0.2 即将支持」

## 核心动作覆盖

满足产品方向.md「切」动作：模式切换 <200ms，状态保留。
