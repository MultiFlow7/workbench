# v0.16.0 · OSS Decoupling

## 概述

v0.16 是工作台首次公开发布前的 OSS 治理基线。它的目标不是新增用户功能，而是解除 v0.15.1 首发 GitHub Release 阻塞：把个人化路径、Vault 配置和发布产物隐私扫描从开发者本机假设中剥离出来，让发布包可以作为面向所有用户的开源桌面应用交付。

当前状态为 **release-closeout / 发布收口中**，尚未发布。

## 已交付范围

- req-063 主体实现：OSS 化改造与个人化信息解耦。
- Vault 运行期配置：Vault 根目录、QA 子目录、Projects 子目录从运行期配置读取。
- 默认 Vault：首次启动创建默认 `~/Workbench-Vault`，并保留权限失败时的备用路径策略。
- Settings Vault 分区：在设置界面中提供 Vault 根目录配置，并支持可选自定义 QA / Projects 目录以接回历史数据。
- 个人路径扫描脚本：用 Node 脚本扫描 build 产物中的本机路径和个人信息泄露风险。
- Release checklist：补充发布前手动检查与验证记录入口。
- 根 CD 隐私扫描：真实 tag 发布 workflow 在打包前执行个人路径扫描。

## 不纳入范围

- req-065 任务 cwd 选择器。
- 新 UI 功能。
- 后端测试覆盖扩展。
- Agent runtime hooks 的完整自动化。
- 大规模历史 changelog 重写。
- 完整删除所有旧桌面壳遗留目录或脚本。
