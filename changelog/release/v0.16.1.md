# 工作台 v0.16.1

v0.16.1 是公开产品洁净度补丁，重点是让仓库和发布产物更适合作为干净的开源产品分发。

## 变更

- 移除已退役的 Tauri 桌面壳目录、脚本、依赖和模板资源，当前桌面运行时统一为 Electron。
- 新增 public cleanliness scanner 与 preflight，覆盖个人路径、公网 IP、疑似密钥、禁止文件、私人关键词、build 产物和 DMG Resources。
- CI/CD 接入发布前洁净度检查，macOS DMG 上传前会解包扫描 Resources。
- Agent SDK、server runner 和 Python sidecar 不再默认全量继承敏感环境变量，改用安全 allowlist。
- Gemini adapter 不再把 API key 放在 URL query 中，ai-service 日志和用户可见错误统一脱敏。
- 本地 settings 文件写入后在 POSIX 平台收紧为当前用户读写。
- 清理公开仓库中的内部规划草案和真实服务地址引用。

## 非范围

- 本版本不实现系统钥匙串或 secure storage。
- 本版本不实现完整 Agent Harness 权限系统。
- Git 历史重写是单独高风险步骤，需要在执行窗口单独确认后进行。
