# 工作台 v0.17.0 · Conversation Relay MVP

## 概述

v0.17.0 是 req-068 的首个可用闭环：工作台可以读取指定 Codex 本地 session，将其映射为 Conversation / QAAtom，并从 Conversation 生成可复制的 Handoff Packet。

本版本验证的是“外部 Agent 入口产生的真实对话能否进入工作台协调层”，不是完整 Claude 同步，也不是 Agent-Agent 协作模型定型。

## 已交付

- 新增 Codex session reader：按 session id 或 `.jsonl` 路径读取 `~/.codex/sessions` 下的本地 Codex 对话。
- 新增 `relay:readCodexSession` IPC：将 Codex 对话配对为 QAAtom，并生成稳定 Conversation。
- 新增 source metadata 保真：QAAtom list/read/write 支持 source 字段；Conversation parse/serialize/update 保留 relay 字段。
- 新增幂等导入：按 `source_session_hash + source_key` 复用已导入 QAAtom，重复读取不重复生成。
- 新增 Conversation Source UI：P4 展示来源平台、脱敏来源、读取状态、未映射事件数。
- 新增 Handoff Packet：P4 可选择目标入口与 handoff mode，生成可复制 Markdown。
- 新增 local-only Read/Handoff Record：完整本地路径只写入 `~/.workbench/relay-records`，Vault Markdown 默认只保存 display/hash。
- 新增未建模事件标记：tool / subagent / unknown event 不强行写入 QAAtom 正式语义。
- 新增 reader 单元测试，覆盖 response_item 读取、event_msg 去重、tool marker、allowlist 拒绝。
- `workbench` package 版本升至 `0.17.0`。

## 隐私与边界

- 只读 Codex 本地 session，不写入 Codex 内部数据。
- 读取路径限制在 `~/.codex/sessions/**/*.jsonl`，并进行 realpath、扩展名和文件大小校验。
- QAAtom / Conversation frontmatter 默认不保存完整 `source_path` / `source_cwd`。
- 完整本地来源细节仅保存在 local-only relay record 中。
- Handoff Packet 默认要求人工确认，不自动发送到外部入口。

## 非范围

- 不做完整 Claude 读取。
- 不做多端实时同步。
- 不写入外部平台内部数据库。
- 不定义 Agent-Agent 最小协作单元。
- 不实现 Memory Agent。
- 不开发独立 cwd selector UI。
- 不做 AI 自动摘要或自动归类。
