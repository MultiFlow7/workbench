A P1 决策角标

当有未处理的 Agent 决策时，P1-Icons 需要某种视觉提示，点击后进入决策模式。约束：不能太抢眼，工具型 App 整体要克制。

A1 · 角标叠在图标上

← 图标列预览
红色角标含数字 "3"
角标叠加在决策图标右上角
优点
  • 数字直观，一眼得知待决策数量
  • 视觉优先级高，不容易被忽略
  • 符合移动端 / 桌面端用户习惯
缺点
  • 红色角标相对抢眼，破坏克制感
  • 需新增决策图标，扩展了 P1 占用

A2 · Inbox 图标 + 小红点

← Inbox 图标变蓝
右上角 6px 红点（无数字）
整体更克制
优点
  • 无数字角标，视觉噪音最低
  • 蓝色高亮 + 小红点区分「有 / 无」两态
  • Inbox 语义清晰，符合「收件箱」心智
缺点
  • 小红点无数量信息，需点进去才知道
  • 需新增图标，P1 栏位增加

缺点
  • TopBar 位置较高，注意力扫描靠后
  • 文字占宽度，TopBar 右侧较拥挤

优点
  • 无额外 UI 弹层，最不打断工作流
  • 精准区分「可用」vs「不可用」功能
  • 符合渐进式降级设计原则
缺点
  • 隐藏较深，用户不主动 hover 难发现
  • 灰色叠 × 视觉语义不够直觉
  • 无全局提示，用户可能困惑为权限问题
建议组合：C2（P3 Banner，可关闭）+ C1 降级（关闭 Banner 后在 TopBar 留红 pip）。Banner 提供初次清晰告知，pip 保留持续感知，两者成本都低。
