# Design Token 命名空间 · v0.15

> 节点 3.2：token 命名空间冻结。本文档列出全部 token 名 + 语义说明，**不写值**。
> 值见 `tokens.css`，可后续微调；命名变更需走 review。

冻结日期：2026-05-29（v0.15 r4）

---

## 1. 表面层级（surface tier）

| 名称 | 语义 |
|------|------|
| `--bg` | 应用根背景（最底层，TopBar / 主区域容器） |
| `--surface` | 一级表面（面板背景、卡片基础色） |
| `--surface-2` | 二级表面（hover 态、嵌入式容器） |
| `--surface-3` | 三级表面（active 态、嵌套卡片头部） |
| `--surface-4` | 四级表面（最高密度区块，如 inline 代码块） |
| `--hover` | 通用 hover 叠加层（rgba 半透明） |

---

## 2. 边框（border tier）

| 名称 | 语义 |
|------|------|
| `--border` | 一级边框（卡片轮廓、面板分隔） |
| `--border-2` | 二级边框（输入框、按钮 idle 态） |
| `--border-3` | 三级边框（高对比情境、滚动条 thumb） |

---

## 3. 文字（text tier）

| 名称 | 语义 |
|------|------|
| `--text` | 主文字（正文 body） |
| `--text-2` | 副文字（说明、副标题） |
| `--text-3` | 弱文字（节点 ID、时间戳、占位） |
| `--text-4` | 最弱文字（disabled、注释） |

---

## 4. 主色与状态色（accent + state）

### 4.1 Accent（主色身份）

| 名称 | 语义 |
|------|------|
| `--accent` | 主色（用户气泡背景、主按钮、active 态） |
| `--accent-h` | 主色 hover 态 |
| `--accent-bg` | 主色淡背景（accent 容器、focus ring base） |
| `--accent-bd` | 主色淡边框 |
| `--accent-fg` | 主色之上文字色（用户气泡文字、主按钮文字） |

### 4.2 状态色（每色配 `-bg` / `-bd`）

| 前缀 | 语义 |
|------|------|
| `--run` | 运行中（蓝色，与 accent 同色族但可独立） |
| `--done` | 完成（绿色） |
| `--pause` | 暂停 / 中断干预（琥珀色） |
| `--err` | 错误（红色） |
| `--think` | 思考块（紫色） |

每个前缀都同时拥有：
- `--X`：主色
- `--X-bg`：淡背景（容器底色）
- `--X-bd`：淡边框

## 5. 阴影 + focus ring

---

## 暗色覆盖

`.dark` 选择器覆盖同一组语义变量名。`--accent-fg` 在两套主题下均为白色（用户气泡文字保持高对比），未在 `.dark` 重复声明。`--focus-ring` 依赖 `var(--accent-bg)` 自动跟随主题。

间距 / 圆角 / 字体 / 动效不随主题变化，仅声明在 `:root`。
